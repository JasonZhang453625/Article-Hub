# Design System

## Brand Colors

| Token | Hex | Usage |
|-------|-----|-------|
| **Deep Sea** (Primary) | `#10273F` | onSurface text, app bar foreground, FAB, headline/title text, settings nav-tile icons |
| **Sea Face** (Primary) | `#00AEEF` | primary ColorScheme, focus borders, selected states, settings section labels, dark mode FAB, dark mode app bar actions, Web platform accent |
| Mist (Light BG) | `#F4F8FB` | scaffoldBackgroundColor (light) |
| Paper | `#FFFFFF` | card surfaces (light), input fills |
| Dune (Secondary) | `#EADFCF` | secondary ColorScheme |
| Dark Surface | `#121A22` | scaffoldBackgroundColor (dark) |
| Dark Card | `#1A2530` | card surfaces (dark) |

## Typography

- **Headlines** (h1, h2): Georgia, weight 700, `#10273F`
- **Title Large**: weight 700, `#10273F`
- **Title Medium**: weight 600, `#10273F`
- **Body Large**: `#10273F`, line-height 1.35
- **Body Medium**: `#4A6678`, line-height 1.4
- **Section labels**: weight 700, letter-spacing 0.8, seaFace

## Component Styles

- **Card border-radius**: 24px
- **Input border-radius**: 20px
- **Chip border-radius**: 20px, pill variant uses 999px (fully rounded)
- **FAB elevation**: 0 (uses Container boxShadow for soft shadow instead)
- **Button elevation**: 0 globally
- **Source platform chips**: padding v:8.5 h:13, fontSize:13
